## 3. Инварианты

- D1: `CameraService.setEnabled()` вызывается только из
  `MainActivity.finishCamConfirm()` (нативный оверлей «Подтвердите тапом на
  экране планшета. Изменение из сети невозможно»); `isEnabled()` читает prefs.
  Сетевой POST /api/settings меняет только зеркальное поле cam.enabled в
  config.json (доказано живо: POST enabled=false не остановил камеру и не
  изменил /health cam.enabled). Сеть может только ПОПРОСИТЬ через
  POST /api/cam/toggle-request -> оверлей; коммит флага - только тап.
- D4: планшет с пустым ws_url не делает исходящих соединений (logcat .5:
  «publish disabled (cam.ws_url/room not set), D4 pull-model»; бюджет 5 попыток
  на .38 исчерпался с честным last_error до подъёма релея). Транзитный ws_url
  остаётся только на gostinaya как переходная дев-схема (relay), в проде -
  pull.
- D2: интерком-пути в этом цикле не менялись; направление server/phone <->
  tablet сохранено.

## 5. Негативные кейсы (раздел 5 requirements)

1. Дашборд без auth -> 401 (именно отсутствие кредов; с кредами 200). PASS.
2. Снапшот выключенной камеры -> HTTP 403 {"error":"disabled"} - по причине
   enabled=false, не сетевая ошибка. Живой прогон через настоящий D1-поток:
   POST /api/cam/toggle-request {"enable":false} -> оверлей «Выключить камеру?»
   на экране .5 (скриншот neg2-overlay-sp5.png) -> тап «Выключить» ->
   /health cam.enabled=false -> снапшот 403 disabled. Обратное включение тем
   же потоком, /health enabled=true, снапшот 200 (5468 байт). До тапа снапшот
   оставался 200 - сеть сама флаг не меняет (доказательство D1 в живую). PASS.
3. WS-кадр без клиентской маски -> close 1002 «unmasked client frame»
   (код сервера 2598-2599; живой прогон: opcode 0x88, payload 1002). PASS.
4. Снапшот при живом стриме -> HTTP 503 {"error":"busy"} (арбитр камеры:
   STREAMING -> SNAP_BUSY; браузер держал viewer gostinaya STREAMING,
   viewers=1). PASS.
5. Включить камеру с сервера -> невозможно: у caching_server нет пути записи
   cam.enabled на планшет (grep - только чтение состояния); сетевой
   toggle-request только показывает оверлей, коммит флага - тап на планшете.
   PASS по дизайну D1.
6. «Смотреть» на комнате без сигналинга -> честное сообщение зрителю
   («сигналинг недоступен (переходная схема) ... показываю свежий снапшот»),
   приложение не падает, киоск жив. PASS (регрессия R8).
7. /api/cam/snapshot?room=nonexistent -> 400 {"error":"unknown room"}, не 500.
   PASS.
